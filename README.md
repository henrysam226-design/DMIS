# DMIS

## Drill Maintenance & Inventory System

DMIS is a digital platform for managing surface drill maintenance, spare-parts inventory, machine operating hours, planned maintenance, stock movements, and maintenance reports.

### Initial Modules

- Dashboard
- Parts Inventory
- Stock Locations
- Stock Movements
- Machines
- Daily Maintenance
- Preventive Maintenance (PM)
- Planned Tasks
- Maintenance History
- Reports
- Users & Permissions

### Initial Drill Fleet

- TD20 — Sandvik DP1500i
- TD21 — Sandvik DP1500i
- TD22 — Sandvik DP1500i

### Project Status

DMIS is currently under development.

The PM configuration will be added when the official maintenance intervals and PM requirements are confirmed.
